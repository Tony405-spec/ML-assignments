# ML Assignments

A small collection of machine-learning assignment notebooks.

## Notebooks

- `ML assignment1 (1).ipynb`: general machine-learning assignment notebook.
- `knn.ipynb`: k-nearest neighbors assignment notebook.

## Quick Start

```bash
python -m venv .venv
python -m pip install --upgrade pip
python -m pip install -r requirements.txt
jupyter notebook
```

Open the notebooks from the Jupyter interface and run cells from top to bottom.

## Reproducibility Notes

- Keep datasets in a documented `data/` folder if future assignments require external files.
- Record random seeds in notebooks when comparing model metrics.
- Clear or explain notebook outputs before submitting large changes.

## Academic Integrity

Use this repository as a learning and reproducibility aid. Do not submit generated or copied work as original coursework without following the rules of the course or institution.
